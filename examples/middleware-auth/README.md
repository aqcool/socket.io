# 中间件身份认证示例

演示如何在 Socket.IO Go 服务端中使用中间件进行基于令牌的身份认证。

## 特性

- 使用命名空间级中间件进行连接认证
- 建立连接前验证令牌
- 需要额外授权的管理员命名空间
- 通过确认回调获取用户资料
- 用户连接和断开通知

## 运行方式

```bash
go run main.go
```

服务端默认监听 `http://localhost:3000`。可通过 `PORT` 环境变量指定其他端口。

## 认证流程

1. 客户端携带认证数据连接：`{ "token": "token-alice" }`
2. 服务端中间件验证令牌
3. 验证成功后建立连接，客户端收到 `welcome` 事件
4. 验证失败时，客户端收到 `connect_error` 事件

## 有效令牌

| 令牌 | 用户名 | 是否为管理员 |
|-------|----------|-------|
| `token-alice` | Alice | 否 |
| `token-bob` | Bob | 否 |
| `token-admin` | Admin | 是 |

## 命名空间

- `/`——主命名空间，需要有效令牌
- `/admin`——管理员命名空间，需要管理员令牌

## 事件

### 主命名空间（`/`）

| 事件 | 方向 | 载荷 | 说明 |
|-------|-----------|---------|-------------|
| `welcome` | 服务端 → 客户端 | `{ message, username }` | 认证成功后发送 |
| `user:connected` | 服务端 → 客户端 | `{ username }` | 用户连接时广播 |
| `user:disconnected` | 服务端 → 客户端 | `{ username }` | 用户断开时广播 |
| `profile` | 客户端 → 服务端 | —（ack） | 请求用户资料 |

### 管理员命名空间（`/admin`）

| 事件 | 方向 | 载荷 | 说明 |
|-------|-----------|---------|-------------|
| `admin:welcome` | 服务端 → 客户端 | `{ message }` | 管理员认证成功后发送 |
| `admin:action` | 客户端 → 服务端 | `string` | 执行管理员操作 |
| `admin:action:result` | 服务端 → 客户端 | `{ success, action }` | 管理员操作结果 |
